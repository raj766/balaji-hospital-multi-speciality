# Balaji Hospital – Next.js Website

Responsive Next.js App Router website concept using the hospital poster's blue, red and white branding.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build for production

```bash
npm run build
npm start
```

## Before publishing

Please have the hospital confirm the exact address, phone numbers, doctors' names and qualifications, services, emergency arrangements and ISO certification. The appointment form opens a WhatsApp message to the primary number; it does not save submissions. Replace the poster-derived building photo with original high-resolution photography after obtaining permission. Add an approved privacy notice and secure backend if patient enquiries will be stored.
